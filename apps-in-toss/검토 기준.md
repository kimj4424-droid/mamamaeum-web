# 엄마마음 앱인토스 검토 기준

이 문서는 지금까지 받은 앱인토스 검토·시스템 피드백을 출시 전 점검 기준으로 정리한 것이다. 기능 변경, AIT 재생성, 재검토 요청 전마다 아래 항목을 확인한다.

## 1. 내비게이션과 화면 전환

- 토스 미니앱 내비게이션 바가 제공하는 뒤로가기를 우선 사용한다.
- 미니앱 화면 내부에는 `← 뒤로가기`처럼 내비게이션 바와 역할이 겹치는 자체 뒤로가기 버튼을 렌더링하지 않는다.
- 토스의 시스템 `backEvent`는 구독하여 동의, 로딩, 결과, 피드백 화면에서 이전 흐름으로 정상 복귀해야 한다.
- 로딩 중에는 별도의 `생성 취소` 행동만 제공하며, 뒤로가기 버튼처럼 중복 표기하지 않는다.
- 입력 수정, 피드백 복귀처럼 화면 맥락에 필요한 행동은 목적이 분명한 문구로 제공한다.

## 2. 대표 사용자 흐름 5종

아래 각 흐름은 오류 없이 완료할 수 있어야 하며, 흐름 중 최소 한 화면에는 AI 답변의 한계를 알리는 안내가 보여야 한다.

1. 엄마에게 하고 싶은 말을 입력하고 답장 제안을 받는다.
2. 부모님에게 받은 카카오톡을 입력하고 답장 제안을 받는다.
3. 제안된 세 답변의 표현 차이와 부모님의 예상 반응을 확인하고 문장을 복사한다.
4. 다른 표현을 다시 생성하거나 입력 내용 수정으로 돌아간다.
5. 동의, 로딩, 결과, 입력 화면 중 노출된 의견 보내기를 통해 피드백을 전송한다.

### AI 안내 문구

- AI 답변은 의료·심리·법률 등 전문가의 답변·진단이 아니며 유일한 정답도 아니라는 안내를 노출한다.
- 중요한 결정 또는 위기 상황에는 신뢰할 수 있는 사람이나 전문기관의 도움을 받도록 안내한다.

## 3. 답변 품질과 사용량 안내

- 결과는 `다정하게`, `차분하고 분명하게`, `솔직하게`의 세 방식으로 명확히 구분한다.
- 각 방식에는 전략 설명, 실제로 보낼 문장, 부모님의 예상 반응을 포함한다.
- 시간당 최대 답변 횟수(현재 IP 기준 30회)를 답장 생성 전 입력 화면에서 알린다.
- 결과 화면에는 `다른 표현 다시 받기`를 제공한다.

## 4. 개인정보 처리방침과 외부 링크

- 개인정보 처리방침 링크는 앱인토스 환경에서 `Device.openURL`로 기기 기본 브라우저 또는 관련 앱을 연다.
- 일반 브라우저에서 네이티브 브릿지를 사용할 수 없으면 처리방침 URL로 현재 탭 이동하는 fallback을 제공한다.
- 처리방침 안의 이메일(`mailto:`), 전화(`tel:`), Anthropic 정책 링크가 유효해야 한다.
- Anthropic 정책 링크는 리디렉션 이후 최종 응답까지 정상인지 확인한다.
- AIT 번들에 개인정보 처리방침을 위한 기존 `target="_blank"` 방식이 남아 있지 않아야 한다.

## 5. 피드백 수집과 운영 알림

- 대표 사용자 흐름 5종 각각에서 이용자가 피드백 버튼을 최소 한 번 마주친다.
- 피드백은 Google Apps Script를 거쳐 지정 Google Sheets에 수합된다.
- 신규 피드백이 수합되면 운영자에게 이메일 알림이 발송된다.
- 피드백 API는 공유 비밀값을 검증하고, 비밀값은 코드·저장소·채팅에 노출하지 않는다.

## 6. 빌드·번들·출시 준비

- 변경 후 `npm run build`가 성공하고 최신 `momslator.ait`가 생성되어야 한다.
- AIT 번들에 최신 코드(외부 링크 처리, 중복 뒤로가기 제거 등)가 실제 포함되어야 한다.
- 출시 전 정적 검토와 대표 흐름 검토를 3회 연속 수행하고, 같은 결함이 없음을 확인한다.
- 최신 AIT가 생성되면 앱인토스 콘솔에 입력할 출시 노트를 함께 작성한다.
- 실제 AIT 업로드, 재검토 요청, 출시처럼 외부 상태를 변경하는 단계는 사용자 승인 직전에 안내한다.

## 7. 보호 대상 파일

- `public/toss-assets/`와 `피드백 관리.md`는 사용자 파일이다.
- 해당 파일과 하위 파일은 명시적 요청이 없는 한 수정하거나 커밋하지 않는다.
